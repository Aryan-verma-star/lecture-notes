Lecture Notes — Docs

Full-stack lecture recorder → AI study notes. Deployed on Vercel + Supabase.

Architecture

This app was migrated to run on Vercel (Hobby) + Supabase (free tier):

  • Database: Supabase Postgres (Prisma, provider postgresql).
  • Audio storage: uploaded directly from the browser to a private Supabase Storage bucket lecture-audio via a short-lived signed URL — never through a Vercel function (4.5 MB body limit).
  • Processing: the transcription → notes pipeline runs synchronously inside the request (maxDuration = 300s), because Vercel freezes functions after the response.
  • Keep-alive: /api/keep-alive runs a real DB query so the free Supabase project doesn't pause after ~7 idle days.

Deploy to Vercel

Step 1 — Import

  1. Go to vercel.com → sign in with GitHub.
  2. Add New → Project → import Aryan-verma-star/lecture-notes → Import.
  3. Framework auto-detects as Next.js. Click Deploy (first deploy may fail without env vars — continue).

Step 2 — Environment Variables

Project → Settings → Environment Variables. Add every variable below (real values; the bucket + tables already exist):

KeyValue
DATABASE_URLSupabase pooler, port 5432: postgresql://postgres.<ref>:<pw>@aws-<region>.pooler.supabase.com:5432/postgres?pgbouncer=true&connection_limit=1
SUPABASE_URLhttps://<project-ref>.supabase.co
SUPABASE_SERVICE_ROLE_KEYservice-role key (server only)
GEMINI_API_KEYyour real Gemini key
GEMINI_MODELgemini-3.7-flash
GEMINI_FALLBACK_MODELSgemini-3.6-flash,gemini-2.5-flash
GEMINI_TIMEOUT_MS300000
GEMINI_MOCK0 (real AI in production)
AUTH_SECRETgenerate: openssl rand -hex 32
MAX_AUDIO_BYTES209715200
GITHUB_TOKEN / GITHUB_REPOleave blank (backup disabled)
GITHUB_BRANCHmain
GITHUB_BASE_DIRsubjects

Step 3 — Redeploy

Deployments → Redeploy. The build (prisma generate && next build) must pass.

Step 4 — Account & verify

Log in at the Vercel URL with the pre-created account admin@lecturenotes.app (or run npx tsx scripts/create-user.ts <email> <password> locally). Create a subject → Record ~30s of real speech → a note generates in 1–3 min.

Step 5 — Keep Supabase awake

On cron-job.org (free): Create Cronjob → URL https://YOUR-APP.vercel.app/api/keep-alive → every 12 hours.

Using the app

  • Record — pick a subject, start recording (mic) or run a timer-only session; the audio uploads straight to Storage and notes appear automatically.
  • Upload Audio File — same direct-to-Storage path; supports MP3/M4A/WAV/WebM.
  • Retry — re-runs the pipeline on a FAILED lecture.
  • Regenerate — re-synthesizes notes (skips transcription if a transcript exists).

Troubleshooting

IssueFix
Prisma ECONNREFUSED / IPv6Use the Supabase pooler URI on port 5432 (session mode).
Upload rejected (403/400)Confirm bucket lecture-audio exists and is private.
Lecture stuck PROCESSINGThe 15-min timeout marks it FAILED → use Retry. Never redeploy mid-processing.
Free tier >50 MB upload failsSupabase free Storage caps objects at 50 MB. Upgrade to Pro or split the recording.
